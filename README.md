# 3D Cell Simulator

An interactive 3D animal cell you can rotate, zoom and click, plus printable / editable CAD models of the same cell.
브라우저에서 돌려 보고 눌러 보는 3D 동물세포 시뮬레이터와, 같은 세포의 3D 프린트·CAD 모델입니다.

## Features
- Drag to rotate, mouse wheel or two-finger pinch to zoom
- Click an organelle to see its name (English + 한국어) and a Korean description; click it again to deselect
- Organelles: cell membrane, nucleus and nucleolus, mitochondria, endoplasmic reticulum, Golgi apparatus, ribosomes, lysosomes
- Hide the membrane to look inside
- Single-file web app (three.js r128 from a CDN), no build step

## How it works
- Rendering: a three.js scene with a perspective camera, ambient and directional light, and one group that holds the whole cell so it rotates as a unit. It rotates slowly when idle.
- Organelles are generated in code: spheres (membrane, nucleus, nucleolus, lysosomes), a torus knot (ER), stacked tori (Golgi), stretched spheres (mitochondria) and small spheres (ribosomes).
- Random layout: 7 mitochondria, 6 lysosomes and 110 ribosomes are placed randomly each time the page loads.
- Interaction: a raycaster picks the clicked organelle. A drag under 6 px counts as a click. The buttons at the bottom select an organelle too.

## Run
Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

Publish with GitHub Pages: Settings, Pages, Deploy from a branch, then `main` and `/ (root)`.

## 3D models (`models/`)
| File | Made by | Use |
|---|---|---|
| `Animal Cell.stl` | Modeled by hand in Fusion | 3D printing |
| `dino_cell_full.stl` | Generated by the scripts in `scripts/` | 3D printing (mesh, about 80 mm wide, one watertight piece) |
| `dino_cell_full.step` | Generated by the scripts in `scripts/` | CAD editing (B-rep solids, mm) |

The generated models use a membrane shell with windows so the inside is visible. Organelles are tied to it with thin struts so the model prints as one piece. Ribosomes are limited to those on the ER.

## Rebuild the generated models
The scripts only rebuild the generated files (`dino_cell_full.stl` and `dino_cell_full.step`). `animalcell.stl` is not produced by them.

```bash
pip install -r requirements.txt
python3 scripts/make_stl.py
python3 scripts/make_step.py
```

## Notes
Organelle positions in the web app are random on each load, while the CAD models use one fixed layout. This is a simplified teaching model and is not to scale.
